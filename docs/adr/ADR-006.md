# ADR-006: Stack dashboard dan sistem token

- Status: **proposed** (yang mengesahkan: Seti)
- Tanggal: 2026-10-29
- Terkait: docs/STRUCTURE.md §1, §5

## Konteks dan pernyataan masalah

Dashboard Otonom adalah control plane, bukan chatbot-first: ia harus
menampilkan antrean approval, timeline audit, dan kartu kasus dengan
jelas, bisa diakses (WCAG 2.2 AA target), dan tidak mengizinkan
perubahan gerbang lewat tampilan. Stack dan sistem token yang dipilih
menentukan apakah janji itu bisa ditepati dan diuji.

## Opsi yang dipertimbangkan

1. **Stack JS/TS dengan pnpm + Turborepo** — sesuai monorepo (ADR-001)
   bila seluruh repo JS/TS; token 3 lapis (primitif, semantik,
   komponen) di `packages/ui-tokens/`; tipografi Inter Tight; gelap
   default + terang; layout 3 area (sidebar, isi, panel Copilot).
2. **Stack poliglot dengan Nx** — bila service memakai bahasa
   berbeda; dashboard tetap satu aplikasi web, tetapi tooling repo
   memakai Nx.
3. Dashboard chatbot-first — ditolak: menyembunyikan antrean approval
   dan status audit di balik percakapan, bertentangan dengan mandat
   dashboard sebagai control plane.

## Keputusan

**Opsi 1 sebagai arah yang diusulkan bila repo JS/TS; opsi 2 bila
poliglot.** Pilihan stack konkret masih terbuka sampai disahkan
Seti. Yang tidak terbuka: dashboard bukan chatbot-first, token 3
lapis, dan target aksesibilitas WCAG 2.2 AA.

## Konsekuensi

- Positif: satu sistem token membuat tampilan konsisten dan bisa
  diuji; layout 3 area menempatkan approval dan audit di tempat yang
  selalu terlihat.
- Negatif: token 3 lapis butuh disiplin (tidak ada warna/ukuran
  hardcode di komponen); stack yang berubah di tengah jalan mahal.
- Mitigasi: `packages/ui-tokens/` terpisah dari komponen; uji axe di
  CI saat dashboard mendarat (Fase 1+).

## Catatan otonomi

Dashboard tidak memberi agent wewenang baru: ia menampilkan status
dan menerima approval manusia. Agent tidak bisa mengubah gerbang,
approval, atau tampilan status audit lewat dashboard (SK-DASH-001/
002, SK-SEC-002; lihat §6 dokumen struktur).
