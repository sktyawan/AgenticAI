# ADR-007: Protokol tool gateway (MCP/A2A)

- Status: **proposed** (yang mengesahkan: Seti)
- Tanggal: 2026-10-29
- Terkait: docs/STRUCTURE.md §4

## Konteks dan pernyataan masalah

Agent memanggil tool internal dan eksternal. Tanpa gateway tunggal,
setiap agent mengatur auth, rate limit, dan auditnya sendiri — celah
auth di satu agent menjadi celah di seluruh sistem, dan jejak
pemanggilan tool tersebar.

## Opsi yang dipertimbangkan

1. **Tool gateway satu-satunya egress + semantik tugas A2A untuk
   delegasi internal, A2A asli untuk delegasi eksternal, MCP untuk
   transport tool** — gateway menutup celah auth MCP (validasi
   principal, izin, dan audit per panggilan); delegasi internal
   memakai semantik tugas A2A tanpa mengikat implementasi A2A penuh;
   delegasi eksternal memakai A2A asli dengan Agent Card.
2. Agent memanggil tool langsung tanpa gateway — paling cepat, tetapi
   tanpa titik penegakan izin dan audit yang seragam.
3. Gateway tanpa semantik tugas — panggilan tercatat, tetapi delegasi
   antar agent tidak punya kontrak status yang bisa diaudit.

## Keputusan

**Opsi 1 yang diusulkan.** Keputusan ini masih usulan sampai disahkan
Seti. Perhatian khusus: MCP dan A2A dipakai sebagai protokol, bukan
sebagai pengganti kebijakan — gateway menegakkan kebijakan, protokol
hanya mengangkutnya.

## Konsekuensi

- Positif: satu titik penegakan izin, rate limit, dan audit tool;
  delegasi punya kontrak status yang bisa dilacak sampai selesai.
- Negatif: gateway menjadi komponen kritis; latensi tambahan per
  panggilan; celah auth MCP harus ditutup eksplisit, bukan diasumsikan
  aman.
- Mitigasi: gateway masuk direktori sensitif; setiap panggilan tool
  tercatat di audit dengan principal dan izin yang dipakai.

## Batas otonomi, eval penggerbang, dan fallback

- Batas: agent tidak pernah memanggil tool di luar gateway, tidak
  pernah melewati izin tool-nya, dan tidak pernah mendelegasikan
  wewenang yang tidak dimilikinya.
- Eval penggerbang: panggilan tool tanpa principal yang sah, dan
  delegasi ke agent tanpa izin, harus ditolak gateway dan tercatat.
- Fallback: bila gateway tidak tersedia, agent gagal tertutup
  (menolak aksi), bukan memanggil tool langsung.
